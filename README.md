# AulaConvert

Una web educativa en español para practicar conversiones de vida diaria, matemáticas, física, química, medidas métricas y sistemas numéricos. El menú está organizado por áreas y las instrucciones explican el flujo de uso. Escribe los decimales con punto (por ejemplo, `2.5`). Está hecha solo con HTML, CSS y JavaScript; no necesita instalar nada ni conectarse a servicios externos. Funciona localmente o como sitio estático en GitHub Pages.

## Verla en el ordenador

Abre `index.html` con cualquier navegador moderno. También puedes publicar la carpeta en GitHub Pages: sube estos archivos a un repositorio y, en **Settings → Pages**, selecciona la rama y la carpeta raíz.

## Archivos

- `index.html`: estructura y contenido de la página.
- `styles.css`: diseño adaptable a móvil y ordenador.
- `app.js`: selección de áreas, cálculos y procedimientos paso a paso.

Las fuentes del diseño son fuentes del sistema y la página no carga recursos de internet.
